## Como rodar

1. Instale o Node.js: <https://nodejs.org>.
2. Abra a pasta do projeto no terminal.
3. Rode o comando:

   ```powershell
   npm start
   ```

4. Abra o navegador em <http://localhost:3000/docs>.
5. Para parar, aperte **Ctrl + C**.
